# Homebrew tap for engineroom

[engineroom](https://github.com/KyleyHarris/engineroom) runs Claude Code sessions on one Mac and
lets you work on them from any other.

```sh
brew install --cask kyleyharris/engineroom/engineroom   # the menu bar app, the program and Zellij
brew install kyleyharris/engineroom/engineroom          # the program and Zellij only
```

`brew upgrade` keeps both at the latest release. The formula and the cask are written by
engineroom's release workflow for each version; change them there, not here.
